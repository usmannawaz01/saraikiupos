# Saraiki UPOS Dataset

A Saraiki corpus in Perso-Arabic script annotated with 17 Universal POS (UPOS) tags. Files are provided in CoNLL-U format with fixed splits.

| Split | Sentences | Tokens |
|---|---:|---:|
| Train | 1,666 | 28,377 |
| Dev | 208 | 3,636 |
| Test | 209 | 3,439 |
| **Total** | **2,083** | **35,452** |

## Online demo

Try the Saraiki UPOS tagger: [Open the interactive demo](https://usmannawaz01.github.io/saraikiupos/).

Enter Saraiki text to view its predicted UPOS tags. 


## Files

- `sarakiupos/train.conllu`
- `sarakiupos/dev.conllu`
- `sarakiupos/test.conllu`

`FORM` contains each token and `UPOS` contains its tag.
